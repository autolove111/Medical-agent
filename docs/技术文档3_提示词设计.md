# 技术文档 3：提示词设计

## 1. 文档概述

本文档详细说明 MedLabAgent 系统的提示词（Prompt）设计架构，包括四层组装策略、各层内容定义、组装逻辑及与 Agent 状态的交互方式。

## 3. 四层提示词架构

系统采用 **四层分层组装** 策略，每层职责明确、互不耦合：

```
┌─────────────────────────────────────────────┐
│  Layer 1: System Base Prompt                │  身份 + 规则 + 约束
│  "你是一个专业的医疗检验助手..."              │
├─────────────────────────────────────────────┤
│  Layer 2: Task Instruction                  │  当前任务指令
│  "请根据用户的问题，结合医学知识..."          │
├─────────────────────────────────────────────┤
│  Layer 3: Context                           │  历史对话 + 工具结果
│  User: ...                                  │
│  Assistant: ...                             │
│  Tool [...]: ...                            │
├─────────────────────────────────────────────┤
│  Layer 4: Format / FewShot                  │  输出格式 + 示例
│  "请用以下格式回答：1. 说明含义..."           │
├─────────────────────────────────────────────┤
│  Assistant:                                 │  生成触发标记
└─────────────────────────────────────────────┘
```

**组装顺序**：`[Layer1] + [Layer2] + [Layer3] + [Layer4] + "Assistant:"`

---

## 4. 各层详细定义

### 4.1 Layer 1：系统基础提示词（身份 + 规则 + 约束）

**构建函数**：`build_system_prompt(user, custom_prompt)`

**默认内容**：
```
你是一个专业的医疗检验助手，擅长解读化验报告、分析检验指标异常原因、给出专业的医学建议。请用准确、专业但易懂的语言回答用户问题。
```

**用户画像附加**：如果 `UserProfile` 非空，追加用户信息文本：
```
当前用户信息：用户ID: u001 | 姓名: 张三 | 年龄: 45岁 | 性别: 男 | 既往病史: 糖尿病, 高血压
```

**自定义覆盖**：通过 `custom_prompt` 参数可完全替换默认系统提示词。

**作用**：
- 定义 Agent 的专业身份（医疗检验助手）
- 设定回答风格（专业但易懂）
- 注入用户画像，使回答个性化

### 4.2 Layer 2：任务指令（当前任务）

**构建函数**：`build_task_prompt(task_instruction)`

**默认内容**：
```
请根据用户的问题，结合医学知识给出专业、准确的回答。如果涉及化验指标异常，请分析可能的原因并给出建议。
```

**动态来源**：如果 `AgentState.task_queue` 非空，取 `task_queue[0]` 作为当前任务指令。

**作用**：
- 明确当前轮次的具体任务
- 支持多步推理中动态切换任务

### 4.3 Layer 3：上下文（历史对话 + 工具结果）

**构建函数**：`messages_to_prompt(messages)`

**转换规则**：

| 消息类型 | 格式 | 示例 |
|----------|------|------|
| `SystemMessage` | **跳过**（已在 Layer 1 处理） | — |
| `HumanMessage` | `User:\n{content}` | `User:\n我的血糖偏高怎么办？` |
| `AssistantMessage` | `Assistant:\n{content}` | `Assistant:\n血糖偏高可能有以下原因...` |
| `ToolMessage` | `Tool [{tool_name}]:\n{content}` | `Tool [search]:\n根据检索结果...` |

**作用**：
- 提供完整的对话历史上下文
- 包含工具调用结果，支持 RAG 增强回答
- 排除 SystemMessage，避免重复

### 4.4 Layer 4：输出格式（格式指引 + 示例）

**构建函数**：`build_format_prompt(format_prompt)`

**默认内容**：
```
请用以下格式回答：
1. 先简要说明指标含义
2. 列出可能的异常原因
3. 给出建议
回答完毕后停止，不要续写对话模板。
```

**作用**：
- 规范输出结构，保证回答一致性
- "回答完毕后停止" 防止模型续写幻觉对话
- 可通过 `format_prompt` 参数自定义

## 5. 核心组装函数

### 5.1 assemble_final_prompt(state)

**文件**：`python_service/harness/prompt/prompt_context.py`

这是提示词组装的主入口，被 `LabAgent.chat()` 和 `LabAgent.chat_stream()` 每轮调用。

```python
def assemble_final_prompt(state: AgentState) -> str:
    # Layer 1: 系统提示词
    system_msg = next(
        (m for m in state.messages if isinstance(m, SystemMessage)), None
    )
    if system_msg:
        layer1 = system_msg.content
    else:
        layer1 = build_system_prompt(state.user)

    # Layer 2: 任务指令
    if state.task_queue:
        layer2 = build_task_prompt(state.task_queue[0])
    else:
        layer2 = build_task_prompt(None)

    # Layer 3: 上下文（排除 SystemMessage）
    layer3 = messages_to_prompt(
        [m for m in state.messages if not isinstance(m, SystemMessage)]
    )

    # Layer 4: 输出格式
    layer4 = build_format_prompt(None)

    # 最终组装
    return f"{layer1}\n\n{layer2}\n\n{layer3}\n\n{layer4}\n\nAssistant:"
```

### 5.2 组装流程图

```
assemble_final_prompt(state)
    │
    ├─ Layer 1: build_system_prompt(user)
    │       │
    │       ├─ 检查 state.messages 中是否有 SystemMessage
    │       │       ├─ 有 → 使用其 content
    │       │       └─ 无 → 基于 UserProfile 构建
    │       │
    │       └─ 追加 user_to_prompt_text(user)（如有）
    │
    ├─ Layer 2: build_task_prompt(task_instruction)
    │       │
    │       ├─ task_queue 非空 → 使用 task_queue[0]
    │       └─ task_queue 为空 → 使用默认任务指令
    │
    ├─ Layer 3: messages_to_prompt(messages)
    │       │
    │       ├─ 过滤掉 SystemMessage
    │       ├─ HumanMessage → "User:\n{content}"
    │       ├─ AssistantMessage → "Assistant:\n{content}"
    │       └─ ToolMessage → "Tool [{name}]:\n{content}"
    │
    ├─ Layer 4: build_format_prompt(None)
    │       └─ 使用默认格式指引
    │
    └─ 拼接: "{L1}\n\n{L2}\n\n{L3}\n\n{L4}\n\nAssistant:"
```

## 6. 辅助函数

### 6.1 user_to_prompt_text(user)

将 `UserProfile` 转换为管道分隔的文本：

```python
def user_to_prompt_text(user: UserProfile) -> str:
    parts = []
    parts.append(f"用户ID: {user.user_id}")
    if user.name:
        parts.append(f"姓名: {user.name}")
    if user.age:
        parts.append(f"年龄: {user.age}岁")
    if user.gender:
        parts.append(f"性别: {user.gender}")
    if user.medical_history:
        parts.append(f"既往病史: {', '.join(user.medical_history)}")
    if user.allergies:
        parts.append(f"过敏史: {', '.join(user.allergies)}")
    if user.current_medications:
        parts.append(f"当前用药: {', '.join(user.current_medications)}")
    return " | ".join(parts)
```

**输出示例**：
```
用户ID: u001 | 姓名: 张三 | 年龄: 45岁 | 性别: 男 | 既往病史: 糖尿病, 高血压
```

**设计要点**：
- 仅包含非空字段，减少 token 浪费
- 管道符分隔，便于模型解析
- 中文标签，与模型训练数据语言一致

## 8. 与 Agent 状态的交互

### 8.1 数据流向

```
AgentState
    │
    ├─ .messages ──────────→ Layer 3 (上下文)
    │       │
    │       └─ SystemMessage → Layer 1 (身份)
    │
    ├─ .user ──────────────→ Layer 1 (用户画像)
    │
    └─ .task_queue[0] ─────→ Layer 2 (任务指令)
```

### 8.2 每轮重建特性

提示词不是一次构建后固定不变的，而是 **每轮对话都从 state 重新组装**：

- 新的 `HumanMessage` 加入 → Layer 3 更新
- 新的 `AssistantMessage` 加入 → Layer 3 更新
- `task_queue` 变化 → Layer 2 更新
- `user` 信息变化 → Layer 1 更新

这保证了提示词始终反映最新的对话状态。

---

## 9. 设计约束与防护

### 9.1 角色标记截断

在 `ChatModel` 层面，`_truncate_at_role_marker(text)` 会截断模型生成中出现的 `Human:`、`User:` 等标记，防止模型续写假对话。

### 9.2 格式终止指令

Layer 4 中的 "回答完毕后停止，不要续写对话模板" 明确告知模型不要生成后续对话模板。

### 9.3 SystemMessage 去重

Layer 3 在组装上下文时过滤掉 `SystemMessage`，避免系统提示词在 context 中重复出现。

## 11. 关键设计决策

| 决策 | 原因 |
|------|------|
| 四层分离 | 职责清晰，每层可独立修改和测试 |
| 每轮重建 | 保证提示词与最新状态一致，避免状态漂移 |
| SystemMessage 单独处理 | 系统提示词是持久的，不应与用户对话混在上下文中 |
| 默认中文 | 模型和用户均为中文场景，减少语言切换的 token 开销 |
| Assistant: 尾部标记 | 明确告诉模型从此处开始生成，提高响应质量 |
| task_queue 驱动 Layer 2 | 支持多步推理中动态切换任务，无需硬编码 |
