# 页面实时刷新机制

## 1. 概览

系统有两条流式通道，都使用 **fetch + ReadableStream**（非 EventSource）消费 SSE：

| 通道 | 后端端点 | 用途 | 协议 |
|------|----------|------|------|
| ReAct 流 | `GET /api/chat/react-stream` | 多步推理（Thought → Tool → Answer） | SSE，单次 GET |
| 普通流 | `POST /api/v1/agent/chat/stream` | 简单对话（逐 token 输出） | SSE，POST body |

---

## 2. ReAct 流式通道（主通道）

### 2.1 前端发起

**文件**：[ApiService.js:277-325](frontend-vue/src/services/ApiService.js#L277-L325)

```javascript
async streamReAct(userId, message, reportId, sessionId, onEvent, onError, onDone) {
    const params = new URLSearchParams()
    params.set("user_id", userId || "default")
    params.set("session_id", sessionId || "default")
    params.set("message", message)
    if (reportId) params.set("report_id", reportId)

    const url = `${prefix}/chat/react-stream?${params.toString()}`
    const response = await fetch(url, { method: "GET", headers: { Accept: "text/event-stream" } })

    const reader = response.body.getReader()
    const decoder = new TextDecoder("utf-8")
    let buffer = ""

    while (true) {
        const { value, done } = await reader.read()    // 读取二进制 chunk
        if (done) break
        buffer += decoder.decode(value, { stream: true })
        const lines = buffer.split("\n")
        buffer = lines.pop() || ""                      // 保留不完整的行

        for (const line of lines) {
            if (line.startsWith("data: ")) {
                const event = JSON.parse(line.slice(6))
                if (event.type === "react_end") { onDone(); return }
                if (event.type === "error")     { onError(event.message); return }
                onEvent(event)                          // ← 分发给渲染层
            }
        }
    }
}
```

**SSE 帧格式**：

```
data: {"type":"thought","step":1,"content":"用户说头疼..."}\n\n
data: {"type":"tool_call","step":1,"name":"search_knowledge","args":{"query":"..."}}\n\n
data: {"type":"observation","step":1,"name":"search_knowledge","result":"未找到..."}\n\n
data: {"type":"final_answer","content":"您好！您提到头疼..."}\n\n
data: {"type":"react_end"}\n\n
```

### 2.2 前端渲染

**文件**：[ChatWindow.vue:287-358](frontend-vue/src/components/ChatWindow.vue#L287-L358)

```javascript
async function sendMessage() {
    // 1. 添加用户消息
    chatStore.addMessage({ role: "user", content: userMessage })

    // 2. 预创建空的助手消息（含 reasoningSteps 数组）
    chatStore.addMessage({ role: "assistant", content: "", reasoningSteps: [] })

    // 3. 流式回调：就地修改最后一条消息
    await ApiService.streamReAct(
        "default", userMessage, currentReportId.value, currentSessionId.value,
        (event) => {
            const last = chatStore.messages[chatStore.messages.length - 1]
            switch (event.type) {
                case "thought":
                    last.reasoningSteps.push({ type: "thought", content: event.content })
                    break
                case "tool_call":
                    last.reasoningSteps.push({ type: "tool_call", name: event.name, args: event.args })
                    break
                case "observation":
                    last.reasoningSteps.push({ type: "observation", name: event.name, result: event.result })
                    break
                case "final_answer":
                    last.content = event.content     // ← 设置最终答案
                    break
            }
            scrollToBottom()                         // ← 每次事件后自动滚动
        }, ...)
}
```

**渲染关键技巧**：

1. **预创建空消息**：先 push 一条空的 assistant 消息到 store
2. **就地修改**：通过 `last.content = ...` 和 `last.reasoningSteps.push(...)` 直接修改对象属性
3. **Vue 响应式**：Vue 3 的 `ref([])` 追踪数组元素的属性变化，自动触发重渲染
4. **每次事件后滚动**：`scrollToBottom()` → `nextTick()` → `container.scrollTop = container.scrollHeight`

**与 ReAct 流的区别**：

| | ReAct 流 | 普通流 |
|--|----------|--------|
| 方法 | GET | POST |
| 事件分隔 | 单个 `\n` | 双 `\n\n` |
| 事件格式 | JSON `{type, ...}` | 纯文本 chunk 或 JSON `{content}` |
| 结束标志 | `{type: "react_end"}` | `[DONE]` |
| 元数据 | 无 | `[META:{...}]` |
| 渲染方式 | 推理步骤面板 + 最终答案 | 直接拼接 `msg.content += chunk` |

## 4. 状态管理

### 4.1 chatStore

**文件**：[chatStore.js](frontend-vue/src/stores/chatStore.js)

```javascript
export const useChatStore = defineStore("chat", () => {
    const messages = ref([])       // 消息列表（响应式）
    const isLoading = ref(false)   // 加载状态
    const error = ref(null)        // 错误信息

    function addMessage(message) {
        messages.value.push({
            id: Date.now(),
            role: message.role,
            content: message.content,
            reasoningSteps: message.reasoningSteps || [],
            timestamp: new Date(),
        })
    }

    function clearMessages() { messages.value = [] }
})
```

**为什么用 `ref([])` 而不是 `reactive([])`**：

- `ref` 包装的数组，替换整个数组（`messages.value = [...]`）会触发响应
- `reactive` 包装的数组，`push`/属性修改也能触发响应
- 流式场景下用 `ref` + 就地修改属性，Vue 3 能正确追踪

function generateSessionId() {
    const id = "sess_" + Date.now().toString(36) + Math.random().toString(36).slice(2, 8)
    localStorage.setItem("session_id", id)
    return id
}
const currentSessionId = ref(localStorage.getItem("session_id") || generateSessionId())

### 5.5 完整持久化数据流

```
┌─ 首次访问 ─────────────────────────────────────────────┐
│                                                         │
│  1. 生成 session_id → 存 localStorage                   │
│  2. 用户发消息 → 后端 ReAct 循环                         │
│  3. 循环结束 → 后端 save_snapshot() → PG                 │
│  4. 用户刷新页面                                        │
│                                                         │
├─ 刷新后 ───────────────────────────────────────────────┤
│                                                         │
│  1. localStorage 恢复 session_id                        │
│  2. 调 GET /chat/history?session_id=sess_xxx            │
│  3. 后端查 short_memory_snapshot 表 → 取最新一条         │
│  4. 过滤出 user/assistant 消息 → 返回 JSON              │
│  5. 前端渲染到 chatStore.messages                       │
│  6. 用户继续对话 → 同一个 session_id → 后端从快照恢复    │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

## 7. 自动滚动

```javascript
const scrollToBottom = async () => {
    await nextTick()                          // 等 DOM 更新
    const container = document.querySelector(".messages-area")
    if (container) {
        container.scrollTop = container.scrollHeight  // 滚到底部
    }
}
```

在每个 SSE 事件回调中调用，确保新内容出现时页面自动跟随。
