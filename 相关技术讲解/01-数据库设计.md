# 数据库设计文档

## 1. 概览

系统使用 **PostgreSQL** 作为主存储，共 4 张核心表，通过 SQLAlchemy ORM 管理。

```
┌─────────────────────────────────────────────────────────────┐
│                      PostgreSQL                              │
│                                                              │
│  ┌──────────────────┐  ┌──────────────────┐                 │
│  │ patient_profile   │  │ session_data     │                 │
│  │ (患者画像)        │  │ (会话事件)        │                 │
│  └──────────────────┘  └──────────────────┘                 │
│                                                              │
│  ┌──────────────────┐  ┌──────────────────┐                 │
│  │ short_memory_     │  │ working_memory_  │                 │
│  │ snapshot          │  │ snapshot         │                 │
│  │ (短期记忆快照)    │  │ (工作记忆快照)   │                 │
│  └──────────────────┘  └──────────────────┘                 │
└─────────────────────────────────────────────────────────────┘
```

数据库连接配置位于 [core/config.py](python_service/core/config.py)：

```python
SQLALCHEMY_DATABASE_URL = "postgresql://medlab_user:medlab_password@localhost:5432/medlab_db"
```

引擎初始化位于 [app/persistence/database.py](python_service/app/persistence/database.py)：

```python
engine = create_engine(DATABASE_URL, pool_pre_ping=True, pool_size=10, max_overflow=20)
SessionLocal = sessionmaker(autocommit=False, autoflush=False, bind=engine)
```

### 2.1 patient_profile — 患者画像表

**用途**：存储患者基本信息 + 认证凭据，每个患者一条记录，跨会话永久存在。

| `name` | String(128) | `""` | 姓名 |
| `age` | Integer | `0` | 年龄 |
| `gender` | String(8) | `""` | 性别 |
| `password_hash` | String(128) | `""` | SHA-256 密码哈希 |
| `blood_type` | String(8) | `""` | 血型 |
| `height` | Float | `0.0` | 身高 cm |
| `weight` | Float | `0.0` | 体重 kg |

| `medications` | Text | `"[]"` | 当前用药 JSON 数组 |
| `family_history` | Text | `"{}"` | 家族史 JSON 对象 |
| `lifestyle` | Text | `"{}"` | 生活方式 JSON 对象 |

**Repository**：[profile_repo.py](python_service/harness/memory/persistence/repositories/profile_repo.py)

**认证相关**：

```python
def _hash_password(password: str) -> str:
```

Token 使用 HMAC 签名，格式为 `{user_id}:{timestamp}:{hmac_sig}`，有效期 7 天。

**用途**：全量持久化所有会话事件（对话消息、化验结果、症状、总结），用于长期记忆召回。

**ORM 模型**：[models.py:65-93](python_service/harness/memory/persistence/models.py#L65-L93)

### 2.3 short_memory_snapshot — 短期记忆快照表

**用途**：保存每轮对话结束时的短期记忆状态（messages + summary），用于会话恢复。**这是前端历史加载的数据来源。**

**ORM 模型**：[models.py:125-148](python_service/harness/memory/persistence/models.py#L125-L148)

| 列名 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `id` | Integer | PK, auto | 自增主键 |
| `patient_id` | String(64) | NOT NULL, idx | 患者 ID |
| `session_id` | String(128) | NOT NULL, idx | 会话 ID |
| `messages` | Text | `"[]"` | 消息列表 JSON |
| `summary` | Text | `"[]"` | 摘要列表 JSON |
| `message_len` | Integer | `0` | 消息总字符数 |
| `created_at` | DateTime | utcnow, idx | 创建时间 |

**messages JSON 结构**：

```json
[
  {"role": "user", "content": "头疼"},
  {"role": "assistant", "tool_calls": [...]},
  {"role": "tool", "tool_call_id": "call_xxx", "content": "未找到相关知识"},
  {"role": "assistant", "content": "您好！您提到头疼..."}
]
```

**summary JSON 结构**：

```json
[
  {"role": "system", "content": "会话摘要（基于历史消息压缩生成）:\n- [要点1]\n- [要点2]"}
]
```

**Repository**：[memory_snapshot_repo.py](python_service/harness/memory/persistence/repositories/memory_snapshot_repo.py)

```python
class MemorySnapshotRepo:
    def save(patient_id, session_id, messages, summary, message_len) -> None
        # 插入一条新快照（每次都是 INSERT，不覆盖旧的）

    def load(patient_id, session_id) -> dict | None
        # 按 id 降序取最新一条，返回 {messages, summary, message_len}
```

**关键设计**：同一个 `session_id` 会产生多条快照记录（每轮对话一条），`load()` 始终取 `ORDER BY id DESC LIMIT 1`，即最新一条。

## 3. 表关系

```
patient_profile.patient_id
    ├── session_data.patient_id          (一对多：一个患者多条会话事件)

    └── 前端生成的 session_id，格式 "sess_{base36timestamp}{random}"
```

## 4. Session 管理

### 4.1 数据库 Session（SQLAlchemy）

```python
# app/persistence/database.py

def get_session() -> Session:
    """获取独立数据库会话（非 FastAPI 上下文）"""
    return SessionLocal()

def get_db() -> Session:
    """获取数据库会话（FastAPI 依赖注入用，generator）"""
    db = SessionLocal()
    try:
        yield db
    finally:
        db.close()
```

**两个入口的区别**：

| 函数 | 用途 | 生命周期 | 谁负责 close |
|------|------|----------|-------------|
| `get_session()` | Repository / 认证路由等非 DI 场景 | 调用方管理 | 调用方手动 `db.close()` |
| `get_db()` | FastAPI `Depends()` 依赖注入 | 请求级 | FastAPI 自动 close |

### 4.2 Repository 的 Session 模式

所有 Repository 支持两种初始化方式：

```python
class ProfileRepo:
    def __init__(self, db: Optional[Session] = None):
        self._db = db
        self._own = db is None   # True = 自己创建 session，自己关

    def _get_db(self) -> Session:
        return self._db if self._db is not None else get_session()

    def _close(self, db: Session):
        if self._own:            # 只有自己创建的才关
            db.close()
```

**单 session 复用**（推荐，避免跨 session 可见性问题）：

```python
db = get_session()
repo = ProfileRepo(db)      # 注入同一个 session
repo.save(...)              # 操作 A
profile = db.query(...)     # 操作 B（同一个 session，立即可见）
db.commit()
db.close()
```

**独立 session**（简单场景）：

```python
repo = ProfileRepo()        # 自动创建 session
repo.get(...)               # 查询完自动关闭
```

## 5. 初始化

```python
# server.py 启动时调用
from app.persistence.database import init_db
init_db()  # 执行 Base.metadata.create_all(bind=engine)
```

`init_db()` 会导入 `harness.memory.persistence.models`，触发所有 ORM 模型注册到 `Base.metadata`，然后自动建表。
