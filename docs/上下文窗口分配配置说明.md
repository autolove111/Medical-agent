# 上下文窗口分配配置说明

## 概述

本项目实现了上下文窗口的智能分配机制，确保模型在处理长对话时能够合理分配 token 资源。

## 当前模型配置

- **模型**：Qwen2.5-7B-Instruct
- **上下文窗口**：32,768 tokens
- **默认分配比例**：
  - 提示词：60%（19,660 tokens）
  - 模型输出：30%（9,830 tokens）
  - 缓冲区：10%（3,276 tokens）

## 配置方式

### 1. 环境变量配置

在 `.env` 文件中添加以下配置：

```bash
# 上下文窗口大小（tokens）
CONTEXT_WINDOW=32768

# 提示词占比（0-1）
PROMPT_RATIO=0.6

# 模型输出占比（0-1）
OUTPUT_RATIO=0.3

# 缓冲区占比（0-1）
BUFFER_RATIO=0.1
```

### 2. 代码中配置

在创建 Agent 时直接传入参数：

```python
from harness.llm_adapter.create_agent import create_agent

agent = create_agent(
    user_id="u001",
    user_name="张三",
    user_age=45,
    # 上下文窗口配置
    context_window=32768,
    prompt_ratio=0.6,
    output_ratio=0.3,
    buffer_ratio=0.1,
)
```

### 3. 动态调整

可以通过修改 `ModelConfig` 来动态调整：

```python
from harness.llm_core.model_loader import ModelConfig, ModelLoader

config = ModelConfig(
    model_path="models/Qwen2.5-7B-Instruct",
    context_window=32768,
    prompt_ratio=0.7,  # 增加提示词占比
    output_ratio=0.2,  # 减少输出占比
    buffer_ratio=0.1,
)

loader = ModelLoader.init(config)
```

## 工作原理

### Token 预算计算

```python
prompt_max_tokens = context_window * prompt_ratio
output_max_tokens = context_window * output_ratio
buffer_tokens = context_window * buffer_ratio
```

### Prompt 截断策略

当 prompt 超过 `prompt_max_tokens` 限制时：

1. **优先截断历史对话**：保留系统提示和任务指令，截断最早的历史对话
2. **逐层截断**：如果历史对话截断后仍超限，逐层截断其他部分
3. **整体截断**：如果所有部分都超限，对整个 prompt 进行截断

### 输出控制

- `max_new_tokens` 参数控制单次生成的最大 token 数
- 系统会确保 `output_max_tokens` 至少为 `max_new_tokens`

## 使用示例

### 示例 1：默认配置

```python
agent = create_agent(user_id="u001")
token_budgets = agent.chat_model.loader.get_token_budgets()

print(f"提示词最大 token 数：{token_budgets['prompt_max_tokens']}")
print(f"模型输出最大 token 数：{token_budgets['output_max_tokens']}")
print(f"缓冲区大小：{token_budgets['buffer_tokens']}")
```

输出：
```
提示词最大 token 数：19660
模型输出最大 token 数：9830
缓冲区大小：3276
```

### 示例 2：自定义分配

```python
# 增加提示词占比，减少输出占比
agent = create_agent(
    user_id="u002",
    prompt_ratio=0.7,
    output_ratio=0.2,
    buffer_ratio=0.1,
)
```

### 示例 3：更大的上下文窗口

```python
# 如果模型支持更大的上下文窗口
agent = create_agent(
    user_id="u003",
    context_window=65536,
    prompt_ratio=0.6,
    output_ratio=0.3,
    buffer_ratio=0.1,
)
```

## 注意事项

1. **比例之和必须为 1**：`prompt_ratio + output_ratio + buffer_ratio` 应该等于 1.0
2. **上下文窗口大小**：应与模型实际支持的上下文窗口大小一致
3. **max_new_tokens**：如果 `output_max_tokens` 小于 `max_new_tokens`，系统会自动使用 `max_new_tokens`
4. **性能影响**：过大的 `prompt_ratio` 可能导致历史对话被过度截断

## 调试信息

系统会在日志中输出 token 预算信息：

```
Agent created | user=u001 model=models/Qwen2.5-7B-Instruct short_memory=enabled | 
Token budget: prompt=19660, output=9830, buffer=3276 (total=32768)
```

当 prompt 超过限制时，会输出警告：

```
WARNING: Prompt exceeds token limit: 25000 > 19660, truncating...
```
